# B2. Carrot Chopdown (Hard Version)

[Problem link](https://codeforces.com/contest/2258/problem/B2)

## Idea

Fix the number of operations $k$ and the length $d$ of every carrot piece that we want to sell.

For one carrot of length $a_i$, the maximum number of pieces of length $d$ is

```math
\min\left(\left\lfloor \frac{a_i}{d} \right\rfloor, 2^k-1\right)
+ [a_i = 2^k d].
```

The value is normally limited to $2^k-1$. We can obtain $2^k$ equal pieces only when the whole carrot has length exactly $2^k d$.

Therefore, for fixed $k$ and $d$,

```math
\boxed{
F(k,d)
=
\sum_i \min\left(\left\lfloor \frac{a_i}{d} \right\rfloor, 2^k-1\right)
+ \#\{i : a_i = 2^k d\}
}.
```

Write $A[k]$ for the answer `ans[k]`. Then

```math
\boxed{A[k] = \max_d F(k,d)}.
```

## Computing the sum

The second term is the number of elements equal to $2^k d$. Store the frequency of each value:

```cpp
freq[a[i]]++;
```

Then query `freq[(1LL << k) * d]`.

In the formulas below, $f[x]$ denotes `freq[x]`.

Let

```math
L = 2^k-1.
```

For any value $a$,

```math
\boxed{
\min\left(\left\lfloor \frac{a}{d} \right\rfloor,L\right)
= [a \ge d] + [a \ge 2d] + \cdots + [a \ge Ld]
}.
```

After summing over all carrots,

```math
\sum_i \min\left(\left\lfloor \frac{a_i}{d} \right\rfloor,L\right)
= \sum_{j=1}^{L} \#\{i : a_i \ge jd\}.
```

Write $S[x]$ for `Suffix[x]`, the number of elements at least $x$:

```math
S[x] = \#\{i : a_i \ge x\}.
```

Then

```math
\sum_i \min\left(\left\lfloor \frac{a_i}{d} \right\rfloor,L\right)
= S[d] + S[2d] + \cdots + S[Ld].
```

Thus,

```math
\boxed{
F(k,d)
= \left(\sum_{j=1}^{L} S[jd]\right)
+ f[(L+1)d]
},
\qquad L=2^k-1.
```

Equivalently,

```math
\boxed{
F(k,d)
= \left(\sum_{j=1}^{2^k-1} S[jd]\right)
+ f[2^k d]
}.
```

Therefore,

```math
\boxed{
A[k]
= \max_d \left(
\sum_{j=1}^{2^k-1} S[jd]
+ f[2^k d]
\right)
}.
```

## Proof

For one carrot, every operation can at most double the number of its pieces. After $k$ operations, it has at most $2^k$ pieces. If its length is not exactly $2^k d$, all $2^k$ pieces cannot have length $d$. Therefore, it contributes at most $2^k-1$ sellable pieces. The value is also limited by $\lfloor a_i/d \rfloor$, because the total carrot length is $a_i$. When $a_i=2^k d$, repeated equal splits can create exactly $2^k$ pieces of length $d$. This proves the formula for one carrot and, after summing, the formula for $F(k,d)$.

For any nonnegative integer $q$,

```math
\min(q,L) = [q\ge1]+[q\ge2]+\cdots+[q\ge L].
```

Set $q=\lfloor a_i/d\rfloor$. The condition $q\ge j$ is equivalent to $a_i\ge jd$. Thus, each indicator sum becomes a suffix-frequency query. Maximizing the resulting value over every possible $d$ gives the best answer for $k$.

Finally, the answers must be nondecreasing. Any plan that uses $k-1$ operations can use one additional operation that does not change its sellable pieces. Therefore, the implementation applies prefix maxima to the answer array.

## Complexity

For each $d$, the pointer visits the multiples of $d$ only once across all values of $k$. The total time is

```math
O\left(n+m+\sum_{d=1}^{m}\frac{m}{d}\right)=O(n+m\log m).
```

The memory usage is $O(m)$.

## Implementation

```cpp
void solve(){
    int n , m ; cin >> n >> m ; 
    vector<int> a(n) ; read(a) ;  

    vector<int> freq(m+1) ;  
    for(auto &x: a) freq[x]++ ;

    vector<int> suff = freq ;  
    for(int i = m-1 ; i >= 0 ; --i) suff[i] += suff[i+1] ;

    vector<int> b(m+1) ;
    for(int d = 1 ; d<=m ; ++d){

        int pos = d ; 
        int total = 0 ;
        for(int k = 1 ;  ;++k){
            int boundary = (1LL<<k)*d ;

            while(pos<=m && pos<boundary){
                total += suff[pos] ;
                pos += d ;
            }
            int tmp = total ; 
            if(boundary<=m){
                tmp += freq[boundary] ;
            }
            b[k] = max(b[k],tmp) ;

            if(boundary>=m)break ;
        }
    }

    for(int i = 1 ; i<=m ; ++i){
        b[i] = max(b[i],b[i-1]) ;
    }
    show(b,1) ; 
}
```
